How To Use This Admin Panel

      
This tool generates HTML code that you paste into your website's index.html file.


      

        
Overview

        

          
Your Biochem Technologies website is a single-page application (SPA) built in one index.html file. All pages are <div> sections that show/hide when you navigate.

          

          
This admin panel generates 3 types of code:

          

          
1. Product Detail Page — A complete product page with description, benefits, properties, applications, and download button. This is what visitors see when they click on a specific product.

          

          
2. Variant List Item — Individual product entries that appear in the grid on category pages (e.g., "Zetasoft AR6" with a "Softener" tag).

          

          
3. Product Group — A complete group block with a header and variant grid (e.g., the entire "ZETASOFT" section with its 4 variants).

        

      


      

        
Step-by-Step Workflow

        

          
Adding a brand new product with a detail page:

          
    
            
  1. Go to "Product Detail Page" tab
    2. 
            
  2. Fill out all the fields
    3. 
            
  3. Click "Generate HTML Code"
    4. 
            
  4. Copy the Page HTML and paste it before </main> in index.html
    5. 
            
  5. Copy the NavMap Entry and add it inside the navMap object in the script
    6. 
            
  6. If the product is in an existing group, add variant-link class and onclick to its variant span
    7. 
            
  7. Place the TDS PDF in the tds/ folder
    8. 
            
  8. Save and test
    9. 
          

          
Adding a new product group to a category page:

          
    
            
  1. Go to "Product Group" tab
    2. 
            
  2. Fill in the group name, description, and variants
    3. 
            
  3. Click "Generate Group HTML"
    4. 
            
  4. Paste the code into the appropriate category page section
    5. 
          

          
Adding variants to an existing group:

          
    
            
  1. Go to "Product Variant" tab
    2. 
            
  2. Add the variant names and tags
    3. 
            
  3. Click "Generate Variant HTML"
    4. 
            
  4. Paste inside the existing <ul class="variants-grid">
    5. 
            
  5. Update the badge count in the group header
    6. 
          

        

      


      

        
Important Notes

        

          
    
            
  • Always back up index.html before making changes
    • 
            
  • The Page ID must be unique and kebab-case (e.g., zetasoft-mx200)
    • 
            
  • If a group has an odd number of variants, add a placeholder: <li class="variant-item" style="background:transparent;border:none;box-shadow:none" aria-hidden="true"></li>
    • 
            
  • TDS PDFs go in the tds/ folder
    • 
            
  • After editing, commit and push to GitHub to update the live site
